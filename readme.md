## Robusta
**Getting Started**

First, configure the database connection settings in `configuration.json`. We recommend using **Qwen3.5-27B** for the experiments.

The following database versions were used in our experiments:

| Database | Version |
|---|---|
| PostgreSQL | 14.23 |
| MySQL | 8.0.45 |
| Oracle | 26ai Free |
| SQL Server | 2022 Developer Edition (16.0.4275.2) |

The standalone LLM experiment uses PostgreSQL 14.23, while the L-error experiment uses **PostgreSQL 18.6**. We recommend using the same database versions for reproducibility.

Install the required dependencies using:

```bash
python -m pip install -r requirements.txt
```

Download the required [CodeT5-small model](https://huggingface.co/Salesforce/codet5-small) from Hugging Face by running:

```bash
python download_codet5_small.py
```

Alternatively, you can download `codet5-small.zip` from GitHub Releases and extract it into the root directory of the Robusta project.
Once the environment is configured, run the following command from the Robusta root directory to start the complete end-to-end workflow:

```bash
python exp/Robusta_experiment/main.py
```

After execution, the experimental results will be saved in the `data/` directory.

To run the LLM experiment independently, execute the following command from the Robusta root directory:

```bash
python exp/llm/main.py
```

Only PostgreSQL is supported. The experimental results will be saved in the `data/LLM_results/` directory.

To run the L-error experiment, first download and set up the TPC-H and JOB datasets. Since this experiment uses PostgreSQL 18.6, configure the database connection settings and experiment switches in `configuration_lerror.json` located in the Robusta root directory.

Then, run the following command from the Robusta root directory:

```bash
python exp/L-error/main.py
```

Only PostgreSQL is supported. The experimental results will be saved in the `data/L-error_results/<experiment>_results/` directory.

**Project Structure**

The main directories are organized as follows:
- **`data/`**: Stores the experimental data and results generated by Robusta.
- **`exp/`**: Intended for scripts used to launch the project.
- **`src/`**: Contains the project source code and supporting resources.
